## What it does

- **Watch front, rear, and side recordings together** — synchronized multi-camera playback for one TeslaCam event
- **Browse Saved, Sentry, and Recent clips** — move through your TeslaCam folders and filter events by type or date instead of opening individual MP4 files
- **Tools for a closer look** — playback controls, screenshots, and export options when reviewing a clip (some advanced tools have usage limits)
- **Your files stay on your device** — no video upload is part of this workflow; optional map and weather features can contact third-party services using location data
- Requires Chrome or Edge for folder access (not supported in Safari or Firefox)

## How to use

1. Connect your drive — insert the USB drive where your TeslaCam recordings are stored
2. Open the viewer in Chrome or Edge and grant access to your TeslaCam folder (or a folder containing it)
3. Browse SavedClips, SentryClips, or RecentClips, choose an event, and review the available camera views
